# CampusPe Landing Page
Next.js 14 (App Router) + plain CSS. Run: `npm install && npm run dev`. Deploy: push to GitHub, import in Vercel.
Reusable components: Button, Pill, Tag, Heading, Check, StepCard (components/ui.js).
Swap placeholders (logo, partner logos, phone screenshots, store badges) with exported Figma assets in /public.
